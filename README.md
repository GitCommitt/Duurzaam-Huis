# README: Duurzaam huis

## Projectomschrijving
In dit project is een duurzaam huis gemaakt die gekoppeld is aan een website. Op de website kan je het huis bedienen en data in zien wat live is vanuit het duurzame huis'*.

---

## Onderdelen & Functionaliteiten

* **Duurzaam huis uiterlijk:** Het huisje is gebouwd met hout en is met een laser snijder gesneden en in elkaar gezet.
* **Website bediening:** Via de website kan je componenten bedienen in het huisje zoals, het lampje.
* **Data inzien:** Via de website kan je data in zien zoals, de temperatuur en het licht.

---

## Technische Realisatie & Componenten

### Hardware & Microcontroller
* **ESP12F:** Gekozen vanwege de wifi functie zodat ik hem kan koppelen aan het netwerk en te bedienen is.
* **Licht sensor:** Met deze sensor kan je zien hoeveel helderheid er in het huisje is.
* **Temperatuur sensor:** Met deze sensor kan je zien hoeveel de temperatuur is in het huisje.
